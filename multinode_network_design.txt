# 多节点CAN网络架构设计

## 1. 网络拓扑结构
- **架构类型**: 线性总线拓扑（星型派生结构，使用CAN集线器）
- **通信介质**: 双绞线屏蔽电缆（CAN_H和CAN_L差分信号）
- **总线长度**: 根据实际需求，基础长度建议不超过1000米
- **终端电阻**: 总线上最远的两个节点各接120Ω终端电阻

## 2. 节点配置

### 现有节点（已定义）
1. **BBB节点** (0x9555AAA0) - BeagleBone Black控制器
   - 功能: 监控中心，网络调试

2. **资源管理器** (0x9555AAA1) - 主控制器
   - 功能: 系统资源分配，任务调度

3. **双向转换器** (0x9555AAA2) - 双向能量转换
   - 功能: 功率管理，电压转换

4. **PV转换器** (0x9555AAA3) - 光伏系统接口
   - 功能: 太阳能发电数据采集和控制

5. **电池转换器** (0x9555AAA4) - 电池管理系统
   - 功能: 电池充放电管理，电量监控

6. **风力涡轮机转换器** (0x9555AAA5) - 风能系统接口
   - 功能: 风力发电数据采集和控制

### 新增节点（扩展）

#### 传感器节点
1. **温度传感器阵列** (0x9555AAA6)
   - 功能: 采集系统各部分温度数据
   - 子节点: 多个DS18B20温度传感器

2. **电流/电压监测节点** (0x9555AAA7)
   - 功能: 监测各节点电流和电压数据
   - 采样率: 100Hz，低优先级周期性发送

3. **环境监测节点** (0x9555AAA8)
   - 功能: 监测环境温度、湿度、光照强度
   - 应用: 智能控制系统环境参数

4. **压力传感器节点** (0x9555AAA9)
   - 功能: 监测系统液压/气压状态
   - 数据格式: 0-100%压力值，8位精度

#### 执行器节点
1. **电机控制节点** (0x9555AAAB)
   - 功能: 控制步进电机或伺服电机
   - 命令类型: 位置控制、速度控制、力矩控制

2. **继电器控制节点** (0x9555AAAC)
   - 功能: 控制多个继电器开关状态
   - 应用: 电源管理、负载切换

3. **显示屏节点** (0x9555AAAD)
   - 功能: LCD/LED显示系统状态
   - 支持文本和简单图形显示

4. **报警节点** (0x9555AAAE)
   - 功能: 声光报警，系统异常通知
   - 支持多级别报警设置

## 3. 通信配置

### 数据传输速率
- **主网络**: 1Mbps（与当前配置一致）
- **扩展传感器子网**: 500Kbps（远距离或节点密集区域）

### 信号传输要求
- **CAN_H和CAN_L电压范围**: 2.5V-3.5V / 1.5V-2.5V
- **差分电压**: 显性状态 > 0.9V，隐性状态 < 0.5V
- **终端电阻**: 120Ω，分布在总线两端

## 4. 网络连接方式
- 所有节点通过CAN收发器（如TJA1050）连接到总线
- 使用CAN集线器进行星型连接，提高可靠性和可维护性
- 关键节点采用冗余连接设计

## 5. 网络扩展建议
- 最多支持110个不同的节点ID
- 当节点数量超过30个时，考虑使用CAN网桥扩展网络
- 长距离传输时，使用CAN中继器增强信号
