# 股票市场信息应用

这是一个基于Python Flask的股票和市场信息分析应用，用于获取和展示股票实时行情、历史数据、K线图、市场热点和财经新闻等信息。应用提供了完整的用户系统、数据可视化和自选股管理功能。

## 项目功能概述

### 1. 用户系统
- 支持用户注册、登录和退出功能
- 使用会话（session）管理用户状态
- 使用SQLite数据库存储用户信息和自选股数据

### 2. 市场概览
- 展示上证、深证、创业板等主要指数的实时行情
- 提供热门股票排行榜（按涨跌幅排序）
- 显示最新财经新闻和相关资讯

### 3. 股票详情
- 查看单个股票的详细报价信息
- 生成并展示股票K线图（包含最高价、最低价标记）
- 支持直接通过URL参数访问股票详情页

### 4. 自选股管理
- 用户可添加、删除和管理自己关注的股票
- 在首页展示用户自选股列表

### 5. 搜索功能
- 提供API接口用于股票搜索
- 支持按股票代码或股票名称搜索

## 核心技术模块

### 1. 数据获取与处理模块
- **StockCrawler类**：负责股票数据、市场指数和新闻的获取
- 支持从文件读取数据和生成模拟数据两种方式
- 使用Pandas处理和分析历史K线数据

### 2. 数据可视化模块
- 使用Matplotlib生成股票K线图
- 支持中文显示和负号显示
- 自动保存图表为PNG图片

### 3. Web服务模块
- 基于Flask框架实现Web服务
- RESTful API设计风格
- 路由管理和模板渲染

### 4. 用户与会话管理
- 基于Flask-Session的用户会话管理
- SQLite数据库持久化存储用户信息和自选股数据
- 自动创建和管理数据库连接

## 技术栈

- **后端**：Python 3.x, Flask
- **数据处理**：Pandas, NumPy
- **数据可视化**：Matplotlib
- **网络请求**：Requests, BeautifulSoup4
- **前端**：HTML, CSS, JavaScript, Bootstrap

## 安装和运行指南

### 1. 环境准备
确保您已安装Python 3.6或更高版本。在Windows系统上，建议使用`py -3`命令来运行Python 3版本。

### 2. 安装依赖包

```bash
py -3 -m pip install -r requirements.txt
```

依赖包包括：Flask, pandas, numpy, matplotlib, beautifulsoup4, requests

### 3. 运行应用

```bash
py -3 app.py
```

### 4. 访问应用
打开浏览器，访问 http://localhost:5000

### 5. 直接访问股票详情页
您可以直接通过以下URL格式访问特定股票的详情页：
```
http://localhost:5000/stock_detail.html?code=股票代码
```
例如：http://localhost:5000/stock_detail.html?code=600519（访问贵州茅台）

## 注意事项

1. **数据说明**
   - 由于这是一个示例应用，大部分股票数据和新闻数据都是模拟生成的
   - 应用会优先从`data`目录下读取数据文件，如果文件不存在或无法读取，则使用模拟数据

2. **文件存储**
   - 生成的K线图图片会保存在`static/charts`目录下
   - 应用会自动创建必要的目录结构

3. **用户数据**
   - 用户数据和自选股数据存储在SQLite数据库（stock_data.db）中，应用重启后数据不会丢失
   - 数据库文件会自动在项目根目录创建
   - 如需重置数据库，删除stock_data.db文件后重新运行应用即可

4. **安全提示**
   - 本应用使用了简单的密钥设置，在生产环境中应使用更安全的密钥管理方式
   - 密码以明文形式存储，在实际应用中应使用加密方式存储密码
