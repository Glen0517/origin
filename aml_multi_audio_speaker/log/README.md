# 【日志目录】程序运行日志，方便调试和问题定位
# aml_multi_audio_speaker - log/目录日志系统说明文档
## 核心定位
本目录为项目**统一日志系统**，为src所有业务模块提供标准化、分级别的日志打印能力，所有日志规则与4类产品分级+宏控裁剪深度绑定，做到「低端极简、高端完整、模块适配」。
日志系统为纯工具层，无任何业务代码，对src业务层零侵入，src仅需引入头文件即可调用。

## 日志核心特性
1. **日志分级**：ERROR(1) > WARN(2) > INFO(3) > DEBUG(4)，等级越高输出越少，量产仅保留ERROR/WARN；
2. **产品适配**：
   - 高端回音壁(1)：DEBUG级，打印全量日志，便于调试；
   - 中端回音壁(2)：WARN级，打印警告+错误日志；
   - 低端音箱(3)/低音炮(4)：ERROR级，仅打印严重错误日志，固件体积最小；
3. **模块联动**：HDMI/光纤/杜比等被裁剪的模块，日志自动屏蔽，无冗余代码；
4. **双端输出**：同时输出到「串口控制台」和「日志文件」，调试+追溯兼顾；
5. **日志轮转**：日志文件超过8MB自动轮转，最多保留5个，防止占满FLASH；
6. **线程安全**：多线程日志输出不乱序，适配嵌入式多线程场景。

## 日志调用方式（src业务层唯一操作，极简！）
1. 在src任意业务文件中，引入日志头文件：
   ```c
   #include "logger.h"

LOG_ERROR("音量调节失败: ret = %d", ret);  // 错误日志，所有产品都打印
LOG_WARN("音量值超限: vol = %d", vol);     // 警告日志，中/高端打印
LOG_INFO("音源切换成功: %s", source);      // 信息日志，高端打印
LOG_DEBUG("当前音量值: %d", vol);          // 调试日志，高端打印

LOG_AUDIO("音频初始化成功，采样率: %d", rate);
LOG_BLUETOOTH("蓝牙配对成功，设备名: %s", name);

//the log is must inited. 
#include "logger.h"
int main(int argc, char *argv[])
{
    log_system_init();  // 日志系统初始化
    // ...其他模块初始化
    return 0;
