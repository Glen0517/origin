# 工程说明、编译部署文档、开发规范

音频无爆音切换：音源切换时的静音消噪处理，是 Soundbar 的基础体验要求；
双进程守护：主程序 + 音频子进程，防止单进程崩溃导致音频中断；
日志轮转：日志文件大小限制 + 自动归档，防止日志占满闪存导致设备死机；
异常自动恢复：音频解码异常、蓝牙断连、HDMI ARC 失联，均能自动复位恢复，无需用户重启。


不变的核心优势（原有架构的精髓，完美继承）

硬件架构不变：AML SOC 主 + MCU 外设从 + UART 通信，SOC 专注音频核心，MCU 专注外设驱动，分工清晰，SOC 无硬件 GPIO 负担，稳定性拉满；
编译部署不变：所有源码编译后仅生成单一可执行文件，量产时只需拷贝一个文件到设备，部署极简，无依赖问题；
脚本控制不变：所有启停 / 升级 / 产测逻辑由 shell 脚本控制，业务代码纯净，修改启停规则无需重新编译；
模块解耦不变：所有新增模块均为独立目录，接口清晰，后续新增功能（如 K 歌麦克风、蓝牙立体声）可无缝追加，无侵入性。

最终结论：完善后的架构能力边界

业务层面：完全满足中高端家庭影院 Soundbar 的所有功能需求（杜比解码 + HDMI ARC + 光纤 + 蓝牙 + WIFI + 低音炮联动 + 声场校准 + 红外学习）；✅ 生产层面：完全满足商用量产交付的所有工程需求（产线校准 + 老化测试 + OTA 升级 + 故障自检 + 日志定位 + 防死机）；✅ 扩展层面：架构预留了「K 歌麦克风、蓝牙 5.3、WIFI 投屏增强、多房间联动」的扩展接口，后续升级无重构成本； 落地层面：可直接基于该架构开发、调试、编译、量产，无需再做任何架构调整。

该架构是商用级家庭影院 Soundbar 的标准架构，完全匹配你的硬件选型和业务需求，可放心落地开发！

终极方案：基于这套统一架构代码，无缝实现「高端 Soundbar + 中端 Soundbar + 低端蓝牙音箱 + 独立低音炮 (subwoofer)」4 类产品适配
核心实现思想：一套源码 + 分级宏控 + 模块化裁剪 + 配置驱动
核心原则（重中之重，全程遵守）
不改架构、不拆分支、不复制代码：全程基于你最终版的完整架构树，一行核心业务代码都不删、不重写，所有产品差异通过「编译宏开关 + 配置文件 + 模块化编译」实现；
极致复用：4 类产品共享 95% 的核心代码，差异点仅 5%，开发维护成本极低，后续改一个 BUG，4 类产品同时受益；
编译产物独立：不同产品编译出独立的、无冗余的可执行文件，低端机无高端功能的冗余代码，固件体积小、运行内存占用低；
量产无缝兼容：保留你架构中所有「量产生产能力」，4 类产品共用一套产测 / 校准 / 升级脚本，生产端无额外学习成本；
完美继承原有优势：AML 主 + MCU 从的硬件架构、UART 通信、模块解耦、脚本启停、U 盘 / 网络 OTA 升级等，全部保留。
一、先明确：4 类产品的【核心功能 & 硬件差异】（裁剪依据，所有适配基于此，无模糊点）
先把边界定死，所有差异只体现在「功能开关 / 模块编译 / 配置加载」，不体现在代码逻辑，这是一套源码适配多产品的核心前提：
① 高端款 - 旗舰家庭影院 Soundbar
全功能拉满，你的最终架构就是为它量身打造的
硬件：AML 高性能 SOC+MCU+HDMI ARC/eARC + 光纤 + 同轴 + 蓝牙 5.3+WIFI + 独立功放 + 大尺寸 LCD + 红外学习 + 静音麦 + 低音炮蓝牙联动；
功能：杜比 / DTS 解码 + 5.1 虚拟环绕 + 人声增强 + 三轨音量调节 (主 / 低 / 高)+ 全音源 (ARC / 光纤 / 蓝牙 / U 盘 / WIFI/AUX)+ 声场校准 + 全外设 + 双路 OTA + 量产全功能。
② 中端款 - 标准版家庭影院 Soundbar
高端款的「功能精简版」，无高端音效 + 精简外设，核心影音能力保留
硬件：AML 标准 SOC+MCU+HDMI ARC + 光纤 + 蓝牙 5.0 + 简易功放 + 小尺寸屏 + 基础按键；
功能：立体声解码 (无杜比 / DTS)+ 基础 EQ + 双轨音量调节 (主 / 低)+ 核心音源 (ARC / 光纤 / 蓝牙 / U 盘)+ 简易外设 + U 盘 OTA + 基础量产功能。
③ 低端款 - 便携蓝牙音箱 / 桌面音箱
极致精简，仅保留核心音频能力，无复杂音源 / 外设，成本优先
硬件：AML 入门 SOC + 极简 MCU + 蓝牙 5.0+AUX + 单功放 + 几颗 LED 灯 + 物理按键；
功能：单声道 / 立体声解码 + 基础音量调节 + 仅 2 类音源 (蓝牙 / U 盘)+ 无音效 / 无屏显 / 无复杂外设 + U 盘升级 + 极简量产校验。
④ 独立低音炮 - Subwoofer
最特殊的一类，纯从设备，无「播放能力」，只有「音频接收 + 功放驱动」，是 Soundbar 的配套设备，无任何音源管理 / 解码 / 播放逻辑
硬件：AML 极简 SOC (或纯 MCU)+ 蓝牙 5.3 (只收音频)+ 大功率低音功放 + 低音喇叭 + 配对指示灯；
核心逻辑：只做 3 件事 → 蓝牙配对 Soundbar 主机 + 接收主机的蓝牙低音音频流 + 接收主机的音量 / 开关指令，驱动功放和喇叭；无解码、无音源、无按键、无屏显、无存储、无任何播放控制。
